# Mini Metro

A **Mini Metro**–inspired transit management and simulation game built in **C++** and **OpenGL** using the [UPB-Graphics `gfx-framework`](https://github.com/UPB-Graphics/gfx-framework) for the *Elements of Computer Graphics (EGC)* course at the Polytechnic University of Bucharest.
